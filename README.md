# 生活记账本 · 完整搭建教程

## 介绍
一个记账网页：密码就是账号，数据存 Cloudflare，还能绑自己的 Telegram 机器人记账。免费，不用服务器。

## 准备
一个 Cloudflare 账号（免费注册）

## 第一步：创建数据库
1. 后台 → 存储和数据库 → D1 → 创建数据库
2. 名字填：jizhang-db
3. 创建完就行，表不用建，程序第一次打开自动建

## 第二步：创建 Worker
1. 后台 → Workers 和 Pages → 创建应用程序 → 创建 Worker
2. 名字填：jizhang → 点部署
3. 点「编辑代码」，把里面的默认代码全部删掉
4. 把附件 worker.js 的代码全部粘贴进去 → 点部署

## 第三步：绑定数据库
1. 打开这个 Worker → 设置 → 绑定 → 添加绑定
2. 选 D1 数据库，变量名填：DB
3. 数据库选第一步建的 jizhang-db → 点保存

## 第四步：开启访问地址
1. Worker → 设置 → 域和路由
2. workers.dev 把开关打开
3. 访问地址就是：https://jizhang.你的子域名.workers.dev

## 不用填的东西
环境变量：无。密钥：无（程序自动生成，存在数据库里）。

## 第一次使用
- 打开网页，输一个密码点「进入账本」，这个密码就是你的账本
- 换一个密码进去就是另一个账本，数据互相看不见
- 登录后密码记在浏览器里，下次打开不用再输
- 每个 IP 最多建 3 个账本

## 记账
- 选「支出 / 收入」，填备注、金额，点「记一笔」或直接按回车
- 首页自动统计：今日、本月、全部的收入和支出
- 每笔账后面有「修改」「删除」，点之前都要再输一次密码；修改能改类型、金额、备注

## 看账单
- 月账单：首页列表里点月份，看当月每一笔，底部有总计；点「生成长截图」出整月长图，长按保存
- 年账单：按月汇总的表，点某个月能打开那个月的明细账单，也能生成长截图
- 全部账单：按年汇总，点某年能打开年账单
- 月账单、年账单右上角有删除按钮，输密码后整期删掉

## 密码
- 改密码：主页右上角「修改密码」，改完账目数据不丢
- 忘记密码：登录页点「忘记密码」，输任意一个以前用过的密码，就能看到当前密码（只是看，不会改）
- 改过的旧密码都会留档，任何一个用过的都能当找回凭证

## Telegram 机器人记账（可选）
每个人绑自己的机器人，记账只进自己的账本，不会串到别人那里。

### 拿 Token
1. Telegram 搜 @BotFather，点开始
2. 发 /newbot
3. 给机器人起个显示名，随便写
4. 再起个用户名，必须以 bot 结尾（如 mybook_bot），重名就换一个
5. 它回复里 "Use this token" 后面那串长字符就是 Token

### 拿自己的 ID
1. Telegram 搜 @userinfobot，点开始
2. 它回复的 Id 后面那串数字就是你的 ID

### 绑定
1. 登录网页账本，拉到最下面「Telegram 记账机器人」面板（里面也有这几步说明）
2. Token 和 ID 填进去，点「保存并绑定」
3. 私聊你刚建的机器人，发 /start

### 用机器人记账
- 发「外卖-15」→ 记一笔支出 15 元，备注外卖
- 发「卖东西+30」→ 记一笔收入 30 元，备注卖东西
- 记完机器人回复：已计入，外加本月和全部的收入支出汇总
- 点按钮「本月账单」：输出本月每一笔和总计
- 点按钮「全部账单」：输出每个月的汇总和总计
- 点按钮「查看当前密码」：显示网页账本的当前密码
- 在网页改了密码，机器人会自动把新密码发给你
- 机器人只认你绑定的 ID，别人给它发消息它不理，网页上记的账机器人里也能查到

## 常见问题
- 打开是 404：第四步 workers.dev 开关没开
- 输密码进去是空的：密码输错了，一个密码对应一个账本，输错就是新账本
- 数据存哪：Cloudflare 的 D1 数据库，自己不去后台删就一直在
- 要钱吗：Cloudflare 免费额度个人记账完全够用
